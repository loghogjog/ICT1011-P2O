## Decision DICE

Simple guide on how to use `Decision Dice`

### Menu page - choose the number of dice faces (2 - 10)
    * `Top Right Button` - Increase the number of dice faces
    * `Top Left Button` - Decrease the number of dice faces
    * `Bottom Right Button` - Confirm selection
    * `Bottom Left Button` - Return to main menu

### Dice Program - Shake to Roll
    * `Pressing bottom Left Button` - Return to dice menu
    * `Pressing all other buttons`
        - When dice is not rolling - `rolls dice`
        - When dice is rolling - `skips rolling animation`
        - `Holding a button shows the last result`

### QOL Additions
    * Conventional dice used when dice faces <= 6 but changes to numbered
      dice for larger numbers
    * Dice bounces when colliding with borders
    * Borders also light up when dice collides into it
